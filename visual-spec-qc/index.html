Visual QA Platform

你要做哪一件事?

涵蓋「交付前的設計稿自我檢核」與「交付後的設計 × 切版比對」。選一個模式開始。

STEP 00 · 環境確認

連線狀態檢查

進入功能前先確認資料來源已就緒。兩者皆正常才會解鎖下一步。

Figma MCP讀取設計稿圖層 / Variables / Token 尚未檢測
Browser MCP載入測試站抓 DOM / 截圖 尚未檢測
連線由代理人(Figma/Browser MCP)或未來的「可連結查資料的網址」提供。
MODE A · 交付前

設計稿規範檢核

貼上 Figma 檔案的 frame / section 連結,透過 Figma MCP 讀取圖層 JSON,執行自動化規範檢查。

檢查項目:命名語意化 · Token 綁定 · RWD/Auto Layout · 對比度(WCAG AA)。
STEP 01

建立比對配對

一組配對 = 一個 Figma frame ↔ 一個測試網頁 ＋ 對應螢幕斷點。可加多組,一次批次核對多頁、多裝置。
斷點選「多尺寸（全部）」時,會讀取該 Figma section 內同一頁的各 RWD 尺寸(依 frame 名稱的 @寬度,如 @1440 / @576 / @375),分別對照測試網站在相同視窗寬度下的呈現。

🎨 Figma frame 連結🌐 測試網頁連結斷點
連結僅供讀取結構;不會送出任何帳密或個資。
STEP 02

正在核對

兩邊都抓「結構化事實」再逐屬性比對,不是比像素。

STEP 03 · 總覽

核對結果

每組一張卡:還原度、燈號、與「誰要修幾項」。點卡片看逐項明細。

History

歷史紀錄

每次「存檔紀錄」會保存主題、填表人、時間與該次的差異點快照。點「載入」可帶回設定重跑,點「新舊回歸」可與上一筆同主題比對。

此清單存在此瀏覽器(localStorage);接上「可連結查資料的網址」後即可跨人共用。
